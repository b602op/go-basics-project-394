# Генератор паролей (Go)

[![hexlet-check](https://github.com/b602op/go-basics-project-394/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/b602op/go-basics-project-394/actions)

## Возможности
- Генерация пароля заданной длины на основе псевдо-генератора.
- Настройка набора символов: строчные латинские буквы, прописные, цифры, спецсимволы
- Оценка надёжности пароля по 5 критериям.

## Запуск
```bash
go run .
```

```
== Проверка надёжности ==
abc        -> Слабый пароль (оценка 1 из 5)
abcdefgh   -> Слабый пароль (оценка 2 из 5)
abcdef1234 -> Средний пароль (оценка 3 из 5)
Abcdef1234 -> Надёжный пароль (оценка 4 из 5)
Abcdef123! -> Очень надёжный пароль (оценка 5 из 5)
```
